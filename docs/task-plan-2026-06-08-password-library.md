# 本地密码库命名与界面清理计划

## 目标

将产品对外旧称统一为“本地密码库”，移除高风险批量清空入口，把手动锁定入口改成“退出登陆”，并用真实运行截图更新文档后推送远程仓库。

## 执行步骤

1. 盘点 UI、扩展元数据、README、docs 和历史原型中的旧命名与相关描述。
2. 先写回归测试，覆盖产品命名、旧词残留、退出登陆按钮、批量清空入口和复制密码图标。
3. 修改 `src/App.tsx`、`index.html`、`public/manifest.json` 和相关文案文件。
4. 批量替换文档中的旧中文命名，保留代码内部英文 `vault` 标识。
5. 启动 Vite 开发服务，截取创建/解锁、主界面和新增账号等关键截图。
6. 将截图写入 README 的项目截图区域，并运行 `npm test`、`npm run typecheck`、`npm run build`。
7. 检查 diff，提交并推送到 `origin/main`。
