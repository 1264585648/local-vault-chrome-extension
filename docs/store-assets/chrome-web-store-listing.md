# Chrome Web Store 商店文案

## 插件名称

本地密码库

## 简短描述

离线优先的本地密码库，用主密码加密保存账号、密码和 2FA 信息。

## 详细描述

本地密码库是一款离线优先的 Chrome 扩展，适合希望把账号记录保存在本机、不依赖云账号的小范围使用场景。

你可以为每条账号记录设置 20 个字符以内的标题，例如“工作 GitHub”“个人邮箱”“家庭扣款”。同一个网页下的多个账号会自动按网页分组，列表中不重复展示网页地址，便于快速查找和复制。

核心功能：

- 本机加密保存账号记录。
- 支持账号标题、网页 / URL、账号名、密码和 2FA Base32 密钥。
- 按网页分组展示账号，适合同一网站存在多个账号的情况。
- 支持搜索标题、账号或网页。
- 支持一键复制账号、密码和 2FA 验证码。
- 支持加密备份导出和导入。
- 支持 JSON / CSV 导入。
- 支持短时会话：本次弹窗、5 分钟、15 分钟、30 分钟、60 分钟。
- 明文导出需要二次确认。

安全与隐私：

- 数据保存在本机扩展存储中。
- 密码库使用主密码派生密钥后加密保存。
- 不需要注册账号。
- 不上传账号、密码、2FA 密钥或主密码。
- 不包含广告、统计 SDK、远程日志或云同步功能。

使用方式：

1. 安装扩展后，首次打开会要求设置主密码。
2. 创建密码库后，点击“新增”保存账号记录。
3. 在列表中按网页分组查看账号。
4. 点击复制按钮复制账号、密码或验证码。
5. 可按需要导出加密备份，换设备时再导入。

注意：

- 主密码丢失后无法恢复密码库。
- 短时会话为了减少重复输入，会在扩展后台内存中临时保留解锁后的数据，到期或退出后清除。
- 明文导出文件包含敏感信息，只应保存在可信设备，并在使用后妥善清理。

## 权限说明

- `storage`：用于保存本机加密后的密码库。
- `clipboardWrite`：用于在用户点击复制按钮时，把账号、密码或验证码写入剪贴板。

## 隐私政策链接

如果 GitHub 仓库公开，商店后台可填写：

`https://github.com/1264585648/local-vault-chrome-extension/blob/main/docs/store-assets/privacy-policy.md`

如果仓库是私有的，需要把 `docs/store-assets/privacy-policy.md` 发布到一个公开可访问页面，再填写公开 URL。

## 审核说明

本扩展不需要登录账号。审核人员可以直接加载扩展，设置任意主密码后进入密码库。扩展不会连接开发者服务器；账号记录仅保存在本地扩展存储中。

建议审核流程：

1. 加载扩展并打开弹窗。
2. 设置一个主密码。
3. 新增一条账号记录。
4. 观察按网页分组的列表。
5. 测试复制账号、密码或 2FA 验证码。
6. 测试导出加密备份。
